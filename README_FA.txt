بسته وب‌اپ تراز

محتویات:
- index.html: خود برنامه
- manifest.webmanifest: مشخصات نصب‌پذیری
- sw.js: ذخیره پوسته برنامه برای استفاده آفلاین
- icon.svg: آیکن برنامه

روش پیشنهادی فقط با گوشی:
1) فایل ZIP را در گوشی دریافت کنید.
2) در GitHub مخزن taraz2-android را باز کنید.
3) اگر هدف ساخت وب‌اپ است، بهتر است یک مخزن جدا با نام taraz-app بسازید.
4) Add file > Upload files را بزنید و فایل‌های داخل این بسته را آپلود کنید (نه خود ZIP را).
5) در Settings > Pages، منبع را روی Deploy from a branch، شاخه main و پوشه /(root) قرار دهید و Save کنید.
6) پس از انتشار، آدرس Pages را باز کنید. این آدرس HTTPS برای نصب PWA یا تبدیل‌کننده‌های PWA به APK استفاده می‌شود.

نکته: این بسته خودش APK نیست. ساخت APK نیازمند میزبانی HTTPS و سرویس ساخت بیرونی است. نرخ آنلاین به دسترسی اینترنت و اجازه CORS منبع نرخ وابسته است. PIN در این نسخه قفل ساده صفحه است، نه رمزگذاری واقعی.
